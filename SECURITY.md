# Security Policy

## Local-First Privacy Guarantee
`ctxbridge` runs 100% locally on your machine with zero telemetry, zero external network calls, and zero cloud storage.

## Supported Versions
| Version | Supported |
| :--- | :--- |
| `0.2.x` | Yes |
| `< 0.2.0` | No |

## Reporting a Vulnerability
If you discover a security issue (such as SQLite injection, path traversal in adapter sync, or unsafe deserialization), please report it privately via GitHub Security Advisories or open an issue without disclosing sensitive exploit payloads publicly.
